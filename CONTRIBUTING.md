# Contributing

This repository mirrors the indicator lists published with each NSS Research paper on https://nsshq.com/research. The files are rebuilt from the published papers, so changes are not made here by pull request.

## Corrections

If a value is wrong, out of date in a way that matters, or should not be on a list, write to **corrections@nsshq.com**. Please include:

- the paper id, for example NSS-ZM-01;
- the value, defanged (for example `example[.]com`);
- what is wrong, and any public record that shows it.

NSS checks every report. When a published result changes, the paper and its files are corrected, the change is listed on the Corrections page (https://nsshq.com/corrections) with the date, what was wrong and what changed, and this repository is rebuilt. Withdrawn items stay on the record; nothing is quietly deleted.

## Issues and pull requests

Issues and pull requests are read, but the quickest route for a correction is the address above. A pull request that edits the files directly cannot be merged, because the next rebuild would overwrite it.

## Security

To report a security issue in NSS itself, write to security@nsshq.com or see https://nsshq.com/.well-known/security.txt.
